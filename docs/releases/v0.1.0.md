# Geek Monitor 0.1.0 Preview

This is the first packaged preview of the Geek Monitor self-hosted monitoring platform.

## Included

- Quarkus/Kotlin server with PostgreSQL migrations, installation, authentication, monitoring, incidents, notifications, and the Admin Flutter Web console.
- JVM server bundle for Java 21, plus a SHA-256 checksum file.
- Linux Agent binaries and installer are published separately as [Geek Monitor Agent 0.1.0](https://github.com/skyhhjmk/geek-monitor/releases/tag/agent-v0.1.0).

## Install

Download `geek-monitor-0.1.0-server-jvm.tar.gz` and `SHA256SUMS`, verify with `sha256sum --check SHA256SUMS`, then follow the bundled `README.md` and `docs/deployment.md`.

## Acceptance status

This is a preview release; it does not claim production acceptance is complete. The [首版验收报告](https://github.com/skyhhjmk/geek-monitor/blob/master/docs/%E9%A6%96%E7%89%88%E9%AA%8C%E6%94%B6%E6%8A%A5%E5%91%8A.md) records the remaining acceptance gates, including the designated production host/network, the full continuous-run window, and production backup-copy recovery with measured RPO/RTO.
