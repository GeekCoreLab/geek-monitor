# Geek Monitor 首版验收报告

日期：2026-10-12
范围：依据[产品与技术规划](产品与技术规划.md)汇总本地实现、自动化测试和隔离环境演练。本文记录的是阶段性交付结果，不把本机证据表述为生产验收。

## 交付结论

首版功能、管理台、Agent、本地通知链路和运维文档已形成可复核的本机交付；生产级 P1–P4 验收仍未完成。当前代码在 `feat/agent-install-command`。公开 Agent Release 尚未发布，因此安装页生成的 GitHub 最新版下载地址当前不可用。

## 已闭环的本机交付

| 范围 | 结果与证据 |
| --- | --- |
| 管理台和安装初始化 | Flutter Web 初始化、登录和管理页面可运行；浏览器已看到 Agent 列表、全宽布局及注册弹窗生成的 Linux 安装命令。开发环境使用测试管理员 `admin@biliwind.com`。 |

| 通知 | 用户确认 SMTP 测试邮件已到达 `admin@biliwind.com`。隔离演练还覆盖 SMTP/Webhook 失败重试、Outbox 分组、限速、5,000 条事件突发投递，以及重启后待投递通知只投递一次并记录为 `DELIVERED`。 |
| Agent | 注册、凭据吊销、指标上报、可信样本过滤、断网 FIFO 补传、失联事件和恢复均有本机测试；双 Agent 隔离网络联动通过。100 个真实 Go Agent 进程的短时测试中 100/100 在线。 |
| 数据库与运维 | PostgreSQL/MySQL/Redis 最小权限已用隔离实例验证；备份及空库恢复、保留清理、状态统计和审计功能已有本机演练。V27 把五张检查/指标时间表改为 UTC 月分区；优化后 V26→V27 在 1,440 万指标样本副本上原子迁移耗时 70 秒、生成约 5.08 GB WAL LSN 差，全部样本保留且 24 小时查询裁掉 5 个分区。独立 E2E 还验证 9 个外键、后续错误外键写入拒绝、历史数据、全局执行 ID 去重和身份序列；Rollup 失败原子性和应用重启恢复也在分区结构上复验通过。详细容量与临时空间边界见[容量基线记录](capacity-benchmark.md)。 |
| 交付文档 | 已提供部署/备份恢复、Agent 安装与卸载、数据库监控最小权限、指标与状态字典、告警配置指南。 |

规划文档第 12 节保留了各项详细命令、样本数和测试边界；容量数据见[容量基线记录](capacity-benchmark.md)。
